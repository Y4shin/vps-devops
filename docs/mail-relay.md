# Outbound Mail Relay

This repo now has an opt-in outbound-only SMTP relay service at
`task deploy:mail`.

It is intended for application notifications such as Authentik email, not for a
full mailbox/webmail deployment.

## Hostnames and identity

Recommended SMTP identity:

- SMTP hostname: `mail.<domain>`
- visible sender address: `authentik@<domain>`

For `pplattner.de`, that means:

- SMTP server identity: `mail.pplattner.de`
- sender address: `authentik@pplattner.de`

## Secrets

Add the `sops_mail_secrets` dict to
`ansible/inventories/prod/group_vars/all.sops.yaml` with at least:

```yaml
sops_mail_secrets:
  MAIL_SUBMISSION_PASSWORD: a-strong-random-password
```

Optional:

```yaml
sops_mail_secrets:
  MAIL_DOMAIN: pplattner.de
  MAIL_HOSTNAME: mail.pplattner.de
  MAIL_SUBMISSION_ACCOUNT: authentik@pplattner.de
  MAIL_POSTMASTER_ADDRESS: postmaster@pplattner.de
  MAIL_AUTHENTIK_FROM: authentik@pplattner.de
```

## Deploy

```bash
task deploy:mail
task deploy:authentik
```

The mail playbook will:

1. Create `/opt/vps-devops/mail`
2. Deploy Docker Mailserver in SMTP-only mode
3. Keep it on a dedicated Docker network named `mail`
4. Bootstrap a local sender account
5. Generate DKIM keys for the mail domain

Authentik will automatically use the local relay if `sops_mail_secrets` is
defined when you deploy Authentik.

## DNS

You should create at least:

1. `A mail.<domain> -> <server-ipv4>`
2. `AAAA mail.<domain> -> <server-ipv6>`
3. PTR/rDNS for both IPs -> `mail.<domain>`
4. SPF for `<domain>`
5. DKIM TXT record(s) generated by Docker Mailserver
6. DMARC for `<domain>`

Example SPF starting point:

```txt
v=spf1 a:mail.pplattner.de -all
```

Example DMARC starting point:

```txt
v=DMARC1; p=none; rua=mailto:postmaster@pplattner.de
```

## Show DKIM records

After the first deploy:

```bash
task mail:dkim:info
```

That prints the generated DKIM TXT record file(s) from the VPS so you can copy
them into DNS.

## Notes

- This setup does not publish public SMTP submission or IMAP/POP3 ports.
- It is aimed at local app-to-relay submission only.
- Mail backup/restore is not automated in this repo yet; the persistent state is
  mainly the Docker Mailserver config and DKIM keys under
  `/opt/vps-devops/mail/config`.
